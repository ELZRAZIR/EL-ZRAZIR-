SERVER RULES

قوانين الزرازير

وجودك معنا يعني موافقتك على القوانين التالية. هدفنا مجتمع محترم ومنظم وممتع للجميع.

01

🤝 الاحترام أولاً

احترم جميع الأعضاء. يمنع التنمر أو الإهانة أو الاستفزاز المتعمد أو افتعال المشاكل.

02

💬 استخدم الشات بشكل صحيح

ممنوع السبام أو تكرار الرسائل أو الإزعاج، واستخدم كل قناة في الغرض المخصص لها.

03

🚫 ممنوع الغش والاستغلال

يمنع استخدام الغش أو استغلال الثغرات أو أي وسيلة تضر بتجربة باقي اللاعبين.

04

📢 ممنوع الإعلانات بدون إذن

لا تنشر إعلانات أو روابط سيرفرات ومجتمعات أخرى بدون موافقة الإدارة.

05

🔒 احترام الخصوصية

ممنوع نشر معلومات شخصية أو صور أو محادثات خاصة لأي عضو بدون موافقته.

06

🛡️ التزم بتعليمات الإدارة

اتبع تعليمات طاقم الإدارة، وإذا كان لديك اعتراض يمكنك التواصل معهم بهدوء.

07

🔐 حافظ على أمان السيرفر

ممنوع نشر ملفات أو روابط مشبوهة أو محاولة الإضرار بالسيرفر أو بالأعضاء.

08

⚠️ العقوبات

مخالفة القوانين قد تؤدي إلى تحذير أو كتم أو طرد أو حظر حسب نوع المخالفة وتكرارها.

⚠️ ملاحظة مهمة

الإدارة تحتفظ بحق اتخاذ الإجراء المناسب تجاه أي تصرف يضر بالمجتمع حتى لو لم يُذكر حرفياً في القوانين.
